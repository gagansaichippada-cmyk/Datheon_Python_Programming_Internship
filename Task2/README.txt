STOCK PORTFOLIO PERFORMANCE TRACKER
Datheon Python Programming Internship - Task 2

FILES
- portfolio.py: the Python program
- constituents.txt: S&P 500 ticker/company dataset supplied for this task
- README.txt: project instructions
- portfolio_summary.csv: generated by the program after you enter holdings

FEATURES
- Accepts stock ticker, purchase price, share quantity, and current price
- Checks ticker symbols against constituents.txt when that dataset is present
- Calculates invested value, current market value, gain/loss, and percentage return
- Displays a formatted summary in the terminal
- Writes results to portfolio_summary.csv

SAMPLE PRICES
The program offers a few sample prices for demonstration only. They are NOT live
market prices. You can choose to use a sample price or enter a current price
yourself. The program does not fetch live prices from the internet.

OUTPUT
The program creates portfolio_summary.csv in the same folder. It contains:
symbol, purchase_price, quantity, current_price, invested_value,
current_market_value, gain_loss, gain_loss_percent.

EXAMPLE
If you buy 2 shares at $100 each and enter a current price of $120:
- Invested value = $200
- Current market value = $240
- Gain = $40
- Gain percentage = 20%

NOTE
This is an educational tracker, not investment advice. Verify any prices you enter.
