HANGMAN WORD GUESSING GAME

Requirements:
- Python 3.8 or newer
- No third-party packages required

How to run:
1. Extract this ZIP file.
2. Open a terminal/command prompt in the extracted folder.
3. Run: python hangman.py
   (On some systems, use: python3 hangman.py)

Features:
- Random hidden word selected from the included English word list
- Six incorrect guesses allowed
- ASCII gallows updated after each incorrect guess
- Tracks guessed letters and reveals correctly guessed letters
- Repeated guesses do not cause a penalty
- Input validation and win/loss messages
- Option to play again
